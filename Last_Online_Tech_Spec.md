# Last Online Technical Specification Document

## 最后在线 - 前端技术开发规范 v1.0

------------------------------------------------------------------------

# 1. 项目目标

本文件用于指导AI编程工具完成《Last Online》网页解谜游戏开发。

目标：

制作一个纯前端运行的互动网页游戏。

玩家体验：

像打开一台Windows
XP电脑，通过IE6浏览器访问一个2003年遗留下来的真实网站。

------------------------------------------------------------------------

# 2. 技术方向

推荐技术：

HTML5

CSS3

JavaScript

可选框架：

React / Vue

但是必须保持：

组件化开发。

数据驱动剧情。

# 4. 核心设计原则

## 数据与代码分离

禁止：

把剧情文字直接写入组件。

错误：

    <div>
    欢迎来到青藤镇
    </div>

正确：

读取：

pages.json

------------------------------------------------------------------------

# 5. 页面系统

所有网页由数据驱动。

示例：

pages.json

``` json
{
 "id":"home",
 "title":"Last Online",
 "content":"欢迎来到青藤镇社区",
 "unlock":true
}
```

------------------------------------------------------------------------

# 6. 网站状态系统

游戏核心：

网站会记住玩家行为。

需要全局状态：

    GameState

保存：

-   已访问页面
-   已完成谜题
-   已发现线索
-   网站变化阶段

------------------------------------------------------------------------

示例：

``` json
{
 "visitedPages":[
   "home",
   "forum"
 ],

 "completedPuzzle":[
   "PUZZLE_001"
 ],

 "onlineCount":13
}
```

------------------------------------------------------------------------

# 7. 存档系统

使用：

localStorage

保存：

    last_online_save

------------------------------------------------------------------------

保存内容：

``` json
{
 "nickname":"玩家",

 "progress":70,

 "events":[
   "photo_found",
   "chat_unlocked"
 ]
}
```

# 9. XP组件系统

------------------------------------------------------------------------

## XPWindow

功能：

模拟Windows XP窗口。

参数：

    title

    width

    height

    content

效果：

打开动画。

关闭按钮。

标题栏。

------------------------------------------------------------------------

## XPButton

功能：

XP经典按钮。

状态：

normal

hover

pressed

------------------------------------------------------------------------

## IEBrowser

功能：

模拟IE6。

包含：

-   地址栏
-   工具栏
-   页面区域
-   状态栏

------------------------------------------------------------------------

# 10. 剧情事件系统

使用：

Event Manager

管理网站变化。

------------------------------------------------------------------------

示例：

``` json
{
 "event":"PHOTO_FOUND",

 "condition":
 "PUZZLE_002_COMPLETE",

 "action":
 "ONLINE_COUNT_CHANGE"
}
```

------------------------------------------------------------------------

# 11. 页面变化机制

网站不是静态页面。

根据GameState变化。

例如：

首页：

初始：

    在线人数:
    12

事件触发后：

    在线人数:
    13

------------------------------------------------------------------------

标题变化：

初始：

    Last Online

最终：

    Last Online - Online

------------------------------------------------------------------------

# 12. 谜题系统

统一接口：

``` json
{
"id":"PUZZLE_001",

"type":"password",

"answer":"online",

"reward":"chat_unlock"
}
```

------------------------------------------------------------------------

支持类型：

-   password
-   hidden_click
-   file_unlock
-   timeline_check
-   observation

------------------------------------------------------------------------

# 13. 文件模拟系统

游戏中的文件：

不需要真实下载。

模拟：

    zip文件

    txt文件

    图片文件

    数据库文件

------------------------------------------------------------------------

点击：

打开对应模拟窗口。

------------------------------------------------------------------------

# 14. 图片系统

要求：

支持：

-   图片查看器
-   放大
-   信息查看
-   EXIF模拟

------------------------------------------------------------------------

图片数据：

``` json
{
"name":"graduation_2003.jpg",

"date":"2003-06-18",

"hidden":"shadow"
}
```

------------------------------------------------------------------------

# 15. 音效系统

支持：

事件触发：

    button_click

    window_open

    error

    typing

    loading

------------------------------------------------------------------------

不要持续背景音乐。

------------------------------------------------------------------------

# 16. UI限制

禁止：

-   Tailwind默认样式
-   Material Design
-   现代卡片
-   圆角App布局
-   玻璃效果

必须：

-   手写CSS
-   XP风格
-   固定宽度
-   像素边框

------------------------------------------------------------------------

# 17. 性能要求

游戏完全前端运行。

无需：

服务器。

数据库。

登录系统。

------------------------------------------------------------------------

所有内容：

本地JSON。

------------------------------------------------------------------------

# 18. AI开发执行顺序

建议：

第一步：

搭建IE6模拟器。

第二步：

完成XP组件。

第三步：

完成网站页面。

第四步：

加入剧情JSON。

第五步：

加入谜题系统。

第六步：

加入状态变化。

第七步：

优化视觉细节。

# 19. 最终验收标准

完成后：

玩家应该感觉：

"我不是打开了一个游戏。"

"我打开了一个2003年留下的网站。"

核心体验：

互联网考古。

数字遗迹。

一个仍然在线的网站。
