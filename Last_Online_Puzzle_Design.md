# Last Online Puzzle Design Document

## 最后在线 - 谜题与交互逻辑设计规范 v1.0

------------------------------------------------------------------------

# 文档用途

本文件用于指导AI编程工具实现游戏谜题系统。

每个谜题包含：

-   ID
-   所在页面
-   玩家目标
-   触发条件
-   操作方式
-   正确答案
-   错误反馈
-   解锁内容

------------------------------------------------------------------------

# 总体谜题设计原则

《Last Online》的谜题不是传统密室逃脱。

重点：

让玩家像调查真实网站一样寻找信息。

谜题来源：

-   网页细节
-   图片信息
-   文件内容
-   时间线
-   页面变化
-   隐藏入口

避免：

-   纯数字密码墙
-   随机猜密码
-   与剧情无关的小游戏

# 错误反馈设计

所有错误不能直接告诉答案。

例如密码错误：

不要：

"密码应该是20021225"

应该：

    Access Denied.

    Maybe the answer is somewhere on this website.
