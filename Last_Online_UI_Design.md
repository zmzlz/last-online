# Last Online UI Design Document

## 最后在线 - 网页视觉设计规范 v1.0

------------------------------------------------------------------------

# 1. 总体视觉目标

《Last Online》的核心视觉目标：

让玩家感觉自己打开了一台2003年前后的Windows XP电脑，并通过Internet
Explorer访问到了一个被遗忘的网站。

视觉关键词：

-   Windows XP Luna
-   Internet Explorer 6
-   2000年代中文门户网站
-   Discuz论坛
-   QQ2003
-   Dreamweaver制作网页
-   Flash时代网页
-   互联网遗迹

不要制作成恐怖网站。

恐怖感来自：

-   内容异常
-   时间错乱
-   网站变化
-   数据记录

而不是血腥图片或惊吓效果。

------------------------------------------------------------------------

# 2. 整体美术方向

采用：

Neo XP 风格

定义：

使用现代网页制作水平重新还原2003年的互联网美学。

避免：

-   现代玻璃拟态
-   大圆角卡片
-   Material Design
-   Tailwind默认风格
-   现代App布局

需要：

-   固定宽度
-   像素边框
-   渐变标题栏
-   XP按钮
-   老式网页布局

------------------------------------------------------------------------

# 13. 动画规范

允许：

-   页面淡入
-   XP窗口打开
-   加载条
-   按钮按下
-   文字逐字显示

禁止：

-   3D效果
-   粒子效果
-   现代网页动画
-   过度视觉特效

# 17. 开发限制

禁止：

-   React默认样式
-   Tailwind卡片设计
-   圆角现代UI
-   苹果风格
-   Material Design

必须：

-   手写CSS
-   固定尺寸布局
-   XP窗口风格
-   经典网页结构

------------------------------------------------------------------------

# 18. 最终目标

玩家打开网页后产生：

"这不像一个游戏页面。"

"像是真的找到了一台旧电脑里的网页。"

核心体验：

互联网遗迹。

数字考古。

一个仍然在线的网站。
